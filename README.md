# 黄家俊个人咨询网站

这是一个无需构建工具的静态网站，入口文件为 `index.html`。将整个 `website` 文件夹部署到任意静态托管服务即可。

## 替换个人照片

当前页面在“关于我 · 视觉记录”位置预留了两个个人照片位，并在“生活的一部分”位置预留了两个猫咪照片位。收到合适的照片后，可将图片放入 `assets/`，并把 `index.html` 中对应的 `portrait-placeholder` 替换为 `<img>`；建议个人照片使用自然光、半身肖像和一张工作/生活状态照，猫咪照片可分别突出两只猫的性格，图片宽度至少 1000px。

`assets/crc-wechat-qr.png` 为卡尔罗杰斯中心公众号二维码。

页面已关联 [卡尔罗杰斯中心](https://www.crc-pca.com/) 官网，并保留了文章与中心活动的微信文章入口。

页面会根据浏览器当前月份自动设置春、夏、秋、冬四季主题，并以低对比度的抽象纹理和缓慢动画作为背景装饰；未来可将 `season-ornament` 扩展为你自己拍摄的四季风景图。

## 发布建议

优先推荐 GitHub Pages：新建一个公开仓库，将 `website` 文件夹中的文件放到仓库根目录，在仓库 Settings → Pages 中选择 `Deploy from a branch`、`main` 分支和 `/ (root)`，保存后即可获得公开网址。

如果希望后续更新更方便，也可以使用 Cloudflare Pages 或 Netlify 连接 GitHub 仓库，自动部署每次提交。
